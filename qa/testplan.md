# Тест-план и результаты

45 тест-кейсов из `docs/PLAN.md` §12.3 + самопроверки §12.1. Окружение проверки: headless Chromium (Playwright, программный WebGL SwiftShader, ~10 FPS), локальный `python -m http.server`. Сценарии автопроверок (`*.txt` в таблице) лежат в `qa/scenarios/` — построчные команды `wait:`/`eval:`/`press:`, их можно повторить вручную в консоли браузера (раннер — внешний инструмент, Node в игру не входит); внутри игры — автопилот `tools/autopilot.js`, который подключается через консоль: `import("/tools/autopilot.js").then(m => m.install([...маршрут...]))`.
