# Сценарии автопроверок

Текстовые сценарии, по которым игра проверялась в headless Chromium (раннер — внешний инструмент QA, в игру не входит:
по правилам проекта в папке игры нет Node). Сценарии можно воспроизвести вручную в обычном браузере.

Формат — одна команда в строке:

| Команда | Что делает | Как повторить вручную |
|---|---|---|
| `wait:мс` | пауза | подождать |
| `eval:JS` | выполнить выражение на странице, результат пишется в лог | вставить выражение в консоль DevTools |
| `press:Код` / `down:Код` / `up:Код` | клавиша (`KeyboardEvent.code`) | нажать / зажать / отпустить клавишу |
| `shot:путь` | снимок экрана (путь — в среде проверки) | — |
| `log:текст` | пометка в логе прогона | — |
