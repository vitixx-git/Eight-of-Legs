# Оригинальный house_kit отсутствует

В поставке нет оригинальных GLB и house_kit_manifest.json. Файл availability.json фиксирует это явно. Поддельные GLB и выдуманные данные о треугольниках оригиналов не создавались.

Все 24 типа в предпросмотре построены процедурно. Для дальнейшей работы положите настоящий манифест сюда, а модели — в models/. Затем потребуется проверить повороты, имена материалов, стрелки часов, уровни сидений/крышек, пол, бюджеты и геймплей на реальных сценах.
