# Ожидаемые входные модели

GLB-набор пока не предоставлен. Положите 17 файлов в `models/` и заполните `lab_kit_manifest.json` фактическими метаданными. Шаблон манифеста помечен `pendingAssets: true`; размеры и число треугольников намеренно не выдуманы.

Для запуска загрузки после добавления файлов удалите `pendingAssets` или установите false. `file` — путь относительно манифеста. Поддерживается массив моделей или объект `{models:[...]}`. Реальные идентификаторы и размеры перечислены в `js/lab/layout.js`.

Предпросмотр без набора показывает только процедурную комнату и маркеры недостающего декора — не замену готовым моделям. Исходники S01, C_LabEntry и S10 нужно подключать отдельно; они здесь не создаются.
