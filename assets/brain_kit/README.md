# Ожидаемый набор brain_kit

GLB и исходный манифест не предоставлены. Никакие процедурные замены не являются моделями набора.

Положите оригинальный brain_kit_manifest.json сюда и модели в models/. Установите available=true в availability.json. Поля манифеста и ожидаемые 18 id перечислены в js/brain/layout.js и js/brain/README.md.

Нормализация использует общий js/kit/kitLoader.js; конфигурация — cfg.brain. Предпросмотр показывает происхождение каждого прибора и не скрывает ошибки загрузки.
