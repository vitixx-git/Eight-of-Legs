# Пользовательская кат-сцена (C_User)

Кат-сцена подключается **манифестом** `assets/cutscene/user_cutscene.json`. Код менять не нужно.

Сейчас в манифесте `"type": "builtin"` — показывается встроенный 2D-пролог (7,5 с: ночной город → окно
«Лаборатории №3» → паук спускается на нити). Как только появится ваш файл, замените манифест по одному из образцов.

## Где в сюжете

`js/config.js → CFG.userCutscene`:

| Поле | Значение по умолчанию | Смысл |
|---|---|---|
| `enabled` | `true` | `false` — кат-сцена не показывается вовсе |
| `position` | `'beforeS01'` | `'beforeS01'` — «Новая игра» → C_User → S01 (расширенное интро); `'afterS10'` — S10 → C_User → Итоги → Титры (финальная сцена) |
| `timeout` | `6` | сколько секунд ждать загрузки файла, потом — встроенный пролог |
| `fadeIn` / `fadeOut` | `0.5` / `0.5` | затемнение на входе и выходе, с, звук ролика плавно уводится |
| `fallbackDur` | `7.5` | длительность встроенного пролога, с |
| `preloadOnMenu` | `true` | файл начинает грузиться ещё в главном меню |

Почему по умолчанию «перед S01»: ролик-пролог про город и лабораторию объясняет, откуда в квартире паук,
и не мешает финалу (в S10 уже есть собственный финальный штрих). Если ваш ролик — эпилог, поставьте `afterS10`.

## Форматы

### 1. Видео (`mp4` / `webm`)

```json
{
  "type": "video",
  "src": "my_cutscene.mp4",
  "subtitles": [ { "t": 0.5, "dur": 3.0, "text": "Город спит.", "who": "" } ],
  "keepGameMusic": false
}
```

Файл `my_cutscene.mp4` положите рядом с манифестом. Рекомендуется H.264 + AAC, 960×540 или 1920×1080, до ~30 МБ.
Видео вписывается в кадр 16:9 с полями. `keepGameMusic: true` — музыка игры не глушится (для немых роликов).

### 2. Последовательность кадров (+ необязательный звук)

```json
{
  "type": "frames",
  "frames": { "pattern": "frames/f_{000}.jpg", "count": 90, "start": 1 },
  "fps": 12,
  "audio": "frames/voice.mp3",
  "subtitles": [ { "t": 1.0, "dur": 3.0, "text": "Это я, паук.", "who": "Паук" } ]
}
```

`{000}` — номер кадра с ведущими нулями (`f_001.jpg … f_090.jpg`). Все кадры предзагружаются до старта.

### 3. Таймлайн из картинок-слоёв

```json
{
  "type": "timeline", "duration": 8, "background": "#000000",
  "layers": [
    { "src": "layers/bg_city.png", "t0": 0, "t1": 8,
      "from": { "x": 480, "y": 270, "scale": 1.0, "alpha": 1 }, "to": { "x": 440, "y": 270, "scale": 1.08 } }
  ],
  "subtitles": [ { "t": 3.0, "dur": 3.0, "text": "Один маленький паук решил: этого не будет.", "who": "" } ]
}
```

Координаты — центр слоя в кадре 960×540; между `from` и `to` параметры (`x`, `y`, `scale`, `alpha`, `rot`) идут плавно.

Готовые образцы: `user_cutscene.example.json` (видео), `user_cutscene.frames.example.json`,
`user_cutscene.timeline.example.json`. Скопируйте нужный в `user_cutscene.json` и поправьте пути.

## Поведение

- **Пропуск** — удерживать Пробел 1 с (кольцо в углу). **Esc** — пауза (видео и звук тоже на паузе).
  **M** — без звука / со звуком. Потеря фокуса вкладки — автоматическая пауза.
- Звук ролика подчиняется громкостям «Общая» × «Музыка» и галочке «Без звука» в настройках.
- Мобильные браузеры: `playsinline`; если автозапуск со звуком запрещён — ролик идёт без звука и
  показывается подсказка «M — включить звук».
- **Fallback:** нет манифеста или `"type": "builtin"` — встроенный пролог. Манифест есть, но файл не загрузился
  за `timeout` или повреждён — встроенный пролог и короткое сообщение; игра не блокируется.
- Субтитры — те же, что в остальных кат-сценах (имя говорящего + текст).

## Как проверить

`http://localhost:8000/?debug=1&scene=C_User` — сразу кат-сцена. Полный путь: «Новая игра» в меню.
