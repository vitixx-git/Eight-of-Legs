# SPIDER и SCIENTIST — «Восемь лап — две ноги»

## ROOM_LAB — лаборатория

Яркая лаборатория-мастерская в духе «Фиксиков»: `tools/lab_preview.html`. Процедурная комната, загрузчик набора, состояния декора и запекание трёх фонов. Входные GLB и игровые сцены пока отсутствуют; манифест — явно помеченный шаблон. Подключение и ограничения: [js/lab/README.md](js/lab/README.md).

## DEF_WILL — Воля

Открыть `tools/will_preview.html`: сравнение пяти персонажей, русские кнопки, ввод текста речи, счётчики событий, виды и регрессионные проверки. Нажатие действия снимает паузу, активная кнопка подсвечивается.

```js
import {createWill} from './js/models/will.js';
const will=createWill();
scene.add(will.group);
will.onStomp=()=>{}; // звук WILL_INTRO и необязательная тряска камеры
will.onSyllable=()=>{}; // BRN_TALK_BLIP
will.animator.play('intro'); // 1.5 с, затем idle
will.animator.play('talk',{text:'Посторонним в голове не место.'});
// will.animator.update(dt);
```

API: `{group,joints,animator,shield,tris,onStomp,onSyllable}`. Обработчики можно задать также в opts конкретного play (приоритет над обработчиком модели). `duration` переопределяет длительность речи, иначе 0.07 с на букву. Переходы 0.2 с. Щетина — однотонная геометрия только Воли; лицо учёного остаётся чистым. Общая функция `workCoat.js` строит верх халата, карман и ручки обоим персонажам, сохраняя геометрию учёного. `outline:false` отключает встроенный inverted hull для внешнего рендерера.

Согласования: центр головы 10.3 — отличный от пивота y8.6; ноги согласованы с пивотами, капсулы перекрываются в суставах. Папка сохраняет размер 8×10, но дополнительно наклонена по X на 35°, иначе закрывает лицо и касается пола. Коррекция её локального положения на hand.L удерживает защитную плоскость перед телом; точное касание ремня ладонью требует дополнительной настройки. Полы — упрощённая процедурная анимация, не симуляция ткани. S03, toon.js и звуки отсутствуют: игровое подключение, звук WILL_GRUNT и камера 6.5–9 с не проверены; предпросмотр демонстрирует события, а не подменяет игровую сцену.

## DEF_FEAR — Страх

Открыть `tools/fear_preview.html`. Все модели процедурные; библиотеки локальные.

```js
import {createFear} from './js/models/fear.js';
const fear=createFear();
scene.add(fear.group);
fear.setHideTarget(reflex);
fear.lookAt(spider.group); // Object3D или Vector3 в мировых координатах
fear.animator.play('intro',{onHidden:()=>{}}); // затем автоматически hide
fear.animator.play('tremble',{amount:.5}); // независимый слой, не сбрасывает hide
// fear.animator.update(dt);
```

API: `{group,joints,animator,tris,setHideTarget,lookAt}`. `idle`, `intro`, `hide` смешиваются за 0.15 с. Дрожь — ограниченный интерполированный шум с частотой смены случайных отсчётов 18 Гц, не чистая синусоида; `enabled:false` выключает слой. `outline:false` передаёт обводку внешнему рендереру. Материалы учёного не изменяются и не переиспользуются: режим Страха полностью flatShading.

Согласования: y=7 — пивот головы, y=8.7 — центр. Капсулы используют дешёвые гранёные окончания. `hideSpot` Рефлекса (z=-1.5) попадает внутрь его головы при размерах обеих моделей: добавлен отступ -3.1 см по локальному Z для предотвращения пересечения. Это не точное стояние в hideSpot. Полная треугольная коллизия и читаемость с камерой S03 требуют отдельной приёмки. S03 и three/toon.js отсутствуют, поэтому игровое подключение не выполнено. FEAR_INTRO — внешний звук сцены, аудиофайл не добавлялся.

## DEF_REFLEX — Рефлекс

`tools/reflex_preview.html`: сравнение Рефлекса с учёным высотой 12 см и пауком высотой 3 см, OrbitControls, «Появление», «Пружинящая стойка», пауза и проверки. Библиотеки локальные, внешних файлов модели нет.

```js
import {createReflex} from './js/models/reflex.js';
const reflex = createReflex(); // makeHuman({simple:true, name:'DEF_REFLEX'})
scene.add(reflex.group);
reflex.animator.play('intro', {onBeat: () => {}, onComplete: () => reflex.animator.play('idle')});
// В цикле: reflex.animator.update(dt);
```

API: `{group, joints, animator, hideSpot, tris}`; `tris` исключает обводку. `hideSpot` — локальная точка (0,0,−1.5) за спиной. Сторона R соответствует −X. `head` на y=8.6 — точка крепления, центр головы y=9.8. Радиус носа 0.3 требует полной длины минимум 0.6: значение 0.5 трактуется как длина цилиндрической части. Капсулы имеют низкополигональные конические закругления; длины сегментов ног согласованы с заданными пивотами (2 и 1.9 см). Кроссовки длиной 1.6 направлены вдоль +Z.

Ветка simple использует общий HumanAnimator, отдельные геометрию и процедурные движения; научный вариант и его клипы не изменены. Контур 0.25 см создаётся kit.outline; `userData.outlineApplied` и `noOutline` позволяют внешнему шейдеру не добавлять его повторно. `outline:false` отключает встроенные контуры для внешней обработки. Intro удерживает конечную позу; переход в idle задаёт сцена через onComplete. Звук REF_INTRO не загружается: onBeat выдаёт три сигнала для аудиосистемы игры. S03 и three/toon.js отсутствуют в workspace, поэтому игровая интеграция не выполнена. Проверка выборки вершин не доказывает отсутствие любых пересечений треугольников во всех кадрах.

## SCIENTIST

Открыть `/tools/scientist_preview.html` на том же сервере. Фабрика `makeHuman(spec)` в `js/models/human.js`; `createScientist(opts)` в `js/models/scientist.js`. Возвращает `{ group, joints, animator, setOutfit, setBadge, setFace, tris }`. Текстуры полос, щетины и бороздок генерируются Canvas API; внешних файлов модели нет.

```js
import { createScientist } from './js/models/scientist.js';
const scientist = createScientist({outfit:'work'});
scene.add(scientist.group);
scientist.setBadge(true);
scientist.animator.play('walk');
// В игровом цикле, сантиметры/секунду:
scientist.animator.update(dt,140);
```

`setOutfit('pajama'|'work')` переключает видимость готовых мешей без пересборки. `setFace('neutral'|'surprised'|'tired'|'angry')` — независимый слой. `play(name,{L,stairs,step,onComplete})`: L для wobble, stairs для fall, step 0–2 для wash. Однократные клипы удерживают последнюю позу. `variant:'SLEEPER'` запускает сон; одновременно передайте `outfit:'pajama'`. Положение кровати задаёт сцена через внешнюю группу. `sitUp` (1,6 с) начинается на боку, разворачивает таз на спину, поднимает корпус на 70° от горизонтали и опускает голени. `play('sitUp',{bedHeight:50})` задаёт высоту таза над полом (по умолчанию 50 см); финальная сидячая поза удерживается до следующего play. Кровать и её край задаёт сцена, модель их не создаёт. `hand.L/R` — точки крепления предметов.

Предпросмотр SCIENTIST использует локальные копии Three.js r170 и OrbitControls в tools/vendor (MIT, заголовки лицензии сохранены); обновить кэш: `python tools/cache_three.py`. Предпросмотр: 23 анимации, эмоции, оба наряда, пропуск, отражение, камеры и проверки. Отрицательный scale.x поддерживается встроенной обработкой determinant в Three.js; менять winding общей геометрии вручную нельзя. Отражение — отдельный экземпляр фабрики (один Object3D нельзя одновременно присоединить к двум родителям).

Согласования: длина капсул трактуется как полный размер; конечности перекрываются у шарниров для устранения зазоров. Стопа 26 см направлена по Z. Подол халата — единая замкнутая объёмная оболочка с узким передним разрезом. Талия следует за корпусом, подол использует затухающую пружину (предел 12°) и проекцию вершин за капсулы ног. Это облегчённая процедурная физика, не полноценная симуляция ткани; отсутствие пересечений между треугольниками во всех позах не гарантируется. PASS_CARD — процедурный бейдж, поскольку исходной модели карточки нет. Полосы используют UV-развёртку примитивов, точные 6 см на каждой поверхности не гарантируются. Ходьба использует двухзвенную IK; перемещение внешней группы должна выполнять сцена со скоростью, переданной в update.

Нет исходников игровых сцен, `three/toon.js`, CC0-пака и `PASS_CARD`: интеграция в S01–S10, сравнение с паком и проверка игровой обводки не выполнены. Без них предпросмотр показывает Standard-материалы без игровой обводки. Отсутствие пересечений во всех позах, скольжение ≤3 см и полное закрытие век требуют дополнительной приёмки; кнопка проверок не доказывает эти свойства.

## SPIDER

Самостоятельная процедурная low-poly модель для Three.js r170. Node/npm не нужны. Модель не загружает картинки, текстуры или файлы геометрии. Предпросмотр загружает фиксированную версию библиотеки Three.js и addons с CDN; для первого открытия нужен интернет.

## Запуск

Из этой папки:

```text
python -m http.server 8000
```

Открыть http://localhost:8000/tools/spider_preview.html . Кнопки запускают 11 анимаций, мышь вращает камеру, колесо приближает. Есть виды спереди/сбоку/сверху, пауза, скорость ходьбы, экспорт SPIDER.glb и автоматические проверки. GLB содержит rigid-parented узлы и анимационные клипы; не содержит skinning, который здесь не нужен.

## Подключение

Страница должна объявлять import map для `three` (та же версия, что у игры). Пример есть в tools/spider_preview.html.

```js
import { createSpider } from './js/models/spider.js';
const spider = createSpider();
scene.add(spider.group);
spider.animator.play('walk');
// В цикле сцены; dt в секундах, speed в условных единицах/сек:
spider.animator.update(dt, 22);
```

API: `{ group, bones, animator, tris }`, дополнительно `materials`, `meshes`, `legs` для проверки. Клипы находятся в `group.animations`, имена `SpiderArmature|Spider_Idle` … `SpiderArmature|Spider_Release`. Runtime `play(name, opts)` принимает короткое имя или полное имя клипа. Переход — 0,15 с. Однократные анимации удерживают финальную позу; вернуть управление можно через `play('idle')`. `opts.onComplete` вызывается один раз.

- webShoot: `target` — THREE.Vector3 в мировых координатах.
- climbEdge: `pivot` — THREE.Vector3 относительно группы модели.
- turn: `direction` — +1 / -1.
- earEnter: `distance` — продвижение в локальном +Z.
- sitChair: `target` — смещение приземления относительно Root.

Управляйте внешним положением через `group`, а не через анимируемые кости. Во время скрытой вкладки не вызывайте update; dt ограничивается 0,1 с против скачков.

## Осознанные согласования конфликтов спецификации

- Перечисленные в задании цвета + Shine + Outline требуют 9 материалов. Legs и Joints объединены в `Legs_Joints`, цвета сохранены в атрибуте color. Получается 7 материалов. При подмене на toon важно сохранить vertexColors, иначе суставы потеряют цвет.
- Матовые Standard материалы имеют roughness 0,69; Eyes — 0,3 по отдельному требованию. Shine и Outline — BasicMaterial (неосвещаемые исключения). Обводка помечена `userData.spiderOutline`, автоматическая внешняя обводка для этих мешей не нужна.
- Толщина исходного брюшка с обводкой превышает разрешённую высоту модели. Вертикальный масштаб брюшка скорректирован с 0,85 до 0,75, его смещение по Y с 0,15 до 0,20. Длина тела сохранена. Веер лап расширен для разделения соседних траекторий при шаге ±18°.
- Кончики костей стоят на y=0. Цилиндрическая геометрия лап может заходить ниже земли на часть радиуса; это не IK для неровного пола.
- Нить использует материал Shine ради бюджета; цвет нити белый, а не отдельный #e9e6f0.
- В текущем workspace нет S01, S02, S03, C_Levers, S10, toon.js или CC0-пака. Интеграция и сравнение с паком не выполнены; сцены не создавались и не изменялись.
