# «Восемь лап — две ноги»

Браузерная игра на чистом JavaScript (ES-модули) + Three.js r170 (лежит в `vendor/three/`).
Без Node, сборщиков и внешних ассетов: модели — процедурные из примитивов, звук — синтез Web Audio,
2D — Canvas 2D. Масштаб 3D: **1 единица = 1 см**.

Паук пробирается в голову спящего учёного, побеждает трёх «хозяев головы» — Рефлекса, Страх и Волю —
и проживает за человека одно утро: умыться, собраться, перейти дорогу и уничтожить в лаборатории яд,
которым учёный собирался травить пауков.

## Запуск

### Windows 10/11 — без установки

Дважды щёлкните **`Запустить игру.bat`** в папке игры. Откроется окно маленького локального сервера,
и игра запустится в браузере по умолчанию (<http://localhost:8000/>).

* Ничего ставить не нужно: сервер написан на встроенном в Windows PowerShell и вшит в сам `.bat`.
  Он доступен только с этого компьютера (127.0.0.1 / ::1), прав администратора не требует.
* Не закрывайте окно сервера, пока играете. Выход — закрыть окно или нажать **Q** (или Ctrl+C).
* Повторный запуск, когда игра уже работает, просто откроет её в браузере ещё раз.
* Если порт 8000 занят другой программой, выберется свободный (8001…); сохранения привязаны к адресу,
  поэтому на другом порте прогресс начнётся заново.
* Если Windows спросит, запускать ли файл, — «Запустить» (или «Подробнее» → «Выполнить в любом случае»).
* Если PowerShell недоступен, `.bat` попробует Python (если он установлен).

### Любая система

```bash
cd vosem_lap          # папка с index.html
python -m http.server 8000
```

Открыть <http://localhost:8000/> в свежем Chrome, Edge или Firefox. Звук включается по первому нажатию
клавиши/клику (требование браузеров).

> Открывать `index.html` двойным кликом (file://) нельзя — ES-модули требуют HTTP-сервер.

## Управление

| Действие | Клавиши |
|---|---|
| Движение | W A S D или стрелки |
| Осторожно (3D) / рывок (бои) | Shift |
| Укус / действие | Пробел |
| Использовать / взять | E |
| Пауза | Esc |
| Подтвердить | Enter / Пробел |
| Пропустить кат-сцену | удерживать Пробел 1 с |

Работает в любой раскладке (в т.ч. русской) — ввод по `KeyboardEvent.code`.

S02 «Путь к человеку»: на матрас и на подушку паук перелезает сам — просто идите на край одеяла или подушки
(с матраса на подушку — сбоку или спереди, мимо плеч спящего); паутина (E) — второй путь. К уху можно подойти
с любой стороны подушки: на подушке W ведёт к уху (паук сам скользит по голове), у головы крадитесь с Shift.

## Порядок сцен

```
МЕНЮ → [пользовательская кат-сцена «Пролог»] → S01 Интро → S02 Путь к человеку → S03 Кто здесь главный?
     → S04 Рефлекс → S05 Страх → S06 Воля → C_Levers → S07 Утренние процедуры → C_Wardrobe
     → S08 Сборы → C_ExitHome → S09 Дорога → C_LabEntry → S10 Уничтожение яда → ИТОГИ → ТИТРЫ → МЕНЮ
```

Поражения: S02→S02 (чекпоинт) · S04→S04 · S05→S05 · S06→S06 (только текущий бой) · S07→S07 (чекпоинт) · S08→S08 (чекпоинт)
· S09→S09 (начало) · S10→S10 (чекпоинт). Сохранение — `localStorage` (версия 1), «Продолжить» ведёт
в безопасную точку.

## Пользовательская кат-сцена

Файл-манифест: `assets/cutscene/user_cutscene.json` (форматы: видео, последовательность кадров,
таймлайн-анимация, встроенная). Место показа — `CFG.userCutscene.position` в `js/config.js`
(`'beforeS01'` — как расширенное интро, по умолчанию; `'afterS10'` — как финальная сцена).
Подробности и примеры — `assets/cutscene/README.md`.

## Разработка

Проект — git-репозиторий (ветка `main`, теги `v1.0.0` и `v1.0.1`), коммиты разбиты по областям: vendor, assets, core, three, models,
audio, env, cutscenes, scenes3d, scenes2d, ui, tests, tools, qa, docs. Любое изменение откатывается `git revert <коммит>`.
Сборки нет: правите файлы и обновляете страницу. Node, npm и CDN не используются.

## Обновление: отдельные бои и отверстия в кольцах

После победы над Рефлексом повторять его при поражении Страху больше не нужно.
После победы над Страхом поражение Воле повторяет только бой с Волей.
«Продолжить» сохраняет текущего защитника; победа записывается сразу, до конца анимации.
Старые сохранения v1 совместимы. «Новая игра» по-прежнему начинает историю заново.

В каждом кольце Страха теперь **3 прохода по 62°**, равномерно по окружности.
Белые засечки отмечают все края; отверстия безопасны и при вспышке появления.
Скорость, урон, частота колец, HP и остальные противники не изменены.

Проверки: `?debug=1&test=all&only=save,battle` — 47 проверок.
