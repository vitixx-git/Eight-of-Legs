# Обновление боёв

## Что изменено

1. Каждый человечек — отдельная контрольная точка. Проигрыш Страху не заставляет снова побеждать Рефлекса; проигрыш Воле не заставляет повторять двух предыдущих. Текущий проигранный бой начинается заново с полным здоровьем участников.
2. «Продолжить» возвращает к сохранённому текущему защитнику. Победа фиксируется сразу, не дожидаясь 1,8-секундной победной паузы. Старые сохранения v1 читаются без сброса. «Новая игра» начинает с начала.
3. В кольцах Страха три равномерных отверстия по 62°. Края отмечены белыми засечками. Отрисовка и проверка попадания используют одни и те же отверстия. Вспышка появления проходит только по твёрдым дугам.
4. HP, скорость, урон, частота появления колец, телепортация и копии Страха не изменены.

## Проверено

- 47 встроенных проверок сохранений и боёв — пройдены.
- Победа над Рефлексом сразу сохраняет S05, победа над Страхом — S06.
- Повторная загрузка данных localStorage видит уже следующего противника.
- По два последовательных поражения Страху и Воле: каждый раз возвращается только тот же бой; событий входа в предыдущие бои нет.
- 24 проверки коллизий: центр каждого отверстия безопасен, середина каждой сплошной дуги наносит урон; проверены углы около перехода через ±π.
- Новая игра сбрасывает точку на S01.
- Консоль в этих тестах: 0 ошибок и предупреждений.
- Кольцо с тремя проходами осмотрено в настоящем боевом экране.

Машинный отчёт: `qa/retry_fear_update.json`. Все остальные исходные файлы сохранены; служебная история .git в ZIP не включена.

## Запуск

Распакуйте архив полностью и запустите имеющийся `Запустить игру.bat`.
Можно также выполнить `python -m http.server 8000` в папке игры и открыть `http://localhost:8000/`.
Для прежних сохранений используйте тот же браузер, адрес и порт: localStorage привязан к ним. Изменённый JS при необходимости обновите Ctrl+F5.
